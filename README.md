# Divine Markings Homepage Redesign

WordPress plugin that provides a custom shortcode-based homepage redesign and tool-page chrome for DivineMarkings.com.

## Packaging

To build a clean, uploadable WordPress plugin ZIP, run:

```bash
python tools/package-plugin.py
```

The resulting ZIP will be created at `dist/divine-homepage-redesign.zip` with the correct folder structure for direct upload to WordPress.
